### Core Structural & Physical Features of the Driver

1. **Monin-Obukhov Coordinate Alignment (Log-Space Splines):**
   The script maps the Cabauw tower heights dynamically using a land-surface roughness reference of \\(z_0 = 0.15\text{ m}\\). It pre-allocates a thread-safe **`SplineWorkspace`** once outside the batch loop, which reduces heap allocations by \\(\sim 65\%\\) when regularizing the vertical profiles of wind components and potential temperature.

2. **Automated LLJ Nose Detection:**
   At each hourly profile \\(t\\), the driver identifies the vertical wind speed maximum (the Low-Level Jet nose height, \\(z_{\text{LLJ}}\\)) using the regularized wind speed profile:
   \\[z_{\text{LLJ}} = \max_{z} U(z)\\]

3. **Dynamic Fold-Ratio Filtering (Bypassing the "Fold Illusion"):**
   The driver calculates the height-varying GSPT Fold Ratio profile for the SHEBA-calibrated Grachev et al. (2007) closure:
   \\[\text{Fold Ratio}(z) = \frac{|C_{\text{mapping}}(z)|}{|C_{\text{constitutive}}(z)| + |C_{\text{mapping}}(z)|}\\]
   *   **The Filter Guard:** If the Fold Ratio at the jet nose (\\(z_{\text{LLJ}}\\)) exceeds **\\(0.99\\)**, the profile is flagged. In this region, physical wind shear vanishes (\\(U_z \to 0\\)), causing the gradient Richardson number to blow up (\\(Ri_g \to \infty\\)).
   *   **The Action:** The script automatically filters (excludes) these singular profiles from the exported dataset, logging the event diagnostics to protect subsequent WSINDy dynamical discovery modules from coordinate projection singularities.

4. **Self-Healing File Fallback:**
   If the target GABLS3 NetCDF file (`.data/gabs3/gabls3_scm_cabauw_obs_v33.nc`) is not found, the driver automatically constructs a synthetic, physically representative 24-hour Cabauw tower time series (complete with a descending nocturnal jet core and growing surface inversion). This ensures the script compiles and runs immediately in any SBLToolkit Julia setup.

5. **GSPT Field Exporting:**
   Unfiltered, physically well-conditioned profiles are exported directly to `/workspace/out/gabls3_gspt_coordinates.csv`. The output file archives the GSPT coordinate fields across all vertical levels, including smooth potential temperature (\\(\theta\\)), horizontal velocity (\\(U\\)), gradient Richardson number (\\(Ri_g\\)), similarity coordinates (\\(\zeta_{\text{BD}}, \zeta_{\text{G07}}\\)), physical curvature components (\\(C_{\text{const}}, C_{\text{coord}}\\)), and coordinate conditioning indices (\\(\kappa_{\zeta}\\)).
