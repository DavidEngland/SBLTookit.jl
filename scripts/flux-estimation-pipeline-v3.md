### Core Mathematical & Physical Features of the Inversion

1. **Stage 5: Newton-Raphson Inversion of Grachev et al. (2007)**
   The script implements the exact SHEBA-calibrated flux-profile functions:
   \\[\phi_m(\zeta) = 1 + a_m \frac{\zeta(1+\zeta)^{1/3}}{1 + b_m \zeta}, \quad \phi_h(\zeta) = 1 + \frac{a_h \zeta + b_h \zeta^2}{1 + c_h \zeta + \zeta^2}\\]
   where \\(a_m = 5\\), \\(b_m = 5/6.5 \approx 0.76923\\), \\(a_h = 5\\), \\(b_h = 5\\), and \\(c_h = 3\\).
   Because the Grachev formulation has no critical Richardson cutoff (at large \\(\zeta\\), the gradient function \\(R(\zeta)\\) asymptotically grows as \\(\zeta^{1/3}\\) rather than saturating), there are no coordinate singularities near \\(Ri_g = 0.2\\). The script utilizes a robust 1D Newton-Raphson root-finder to solve the non-linear equation \\(R(\zeta) - Ri_g = 0\\). The downstream sensitivity matrix is driven by the exact, analytical first-order derivative \\(R'(\zeta)\\):
   \\[\frac{\partial\zeta}{\partial Ri_g} = \frac{1}{R'(\zeta)} = \left[ \frac{\phi_h + \zeta \phi_h'}{\phi_m^2} - \frac{2\zeta \phi_h \phi_m'}{\phi_m^3} \right]^{-1}\\]

2. **Stage 6: Differential Geometry and Curvature Decomposition**
   The module decomposes the physical vertical spatial curvature of the Richardson number profile (\\(Ri_{zz} \equiv \partial^2 Ri / \partial z^2\\)) at each measurement level:
   \\[Ri_{zz} = \underbrace{Ri_{\zeta\zeta}\zeta_z^2}_{C_{\text{constitutive}}} + \underbrace{Ri_\zeta\zeta_{zz}}_{C_{\text{mapping}}}\\]
   *   **Constitutive Curvature (\\(C_{\text{constitutive}}\\)):** Represents the spatial bending of the empirical closure function itself. It uses the analytical second derivative \\(Ri_{\zeta\zeta}\\) (reconstructed via a highly precise central-difference scheme on the analytical first derivative).
   *   **Mapping Curvature (\\(C_{\text{mapping}}\\)):** Represents the pure geometric bending generated by the coordinate transformation \\(z \mapsto \zeta(z)\\).

   To avoid divisions by zero in neutral/weakly stable conditions (\\(L \to \infty\\)), the script fits a natural cubic spline to the diagnosed \\(\zeta(z)\\) profile and extracts the exact spatial coordinate derivatives \\(\zeta_z\\) and \\(\zeta_{zz}\\) using analytical log-coordinate transformations:
   \\[\frac{d\zeta}{dz} = \frac{1}{z}\frac{d\zeta}{d\xi}, \quad \frac{d^2\zeta}{dz^2} = \frac{1}{z^2} \left( \frac{d^2\zeta}{d\xi^2} - \frac{d\zeta}{d\xi} \right) \quad (\xi = \ln(z/z_0))\\]

3. **Isolating the "Fold Illusion" near the Low-Level Jet Nose**
   Near the axis of a Low-Level Jet (LLJ), wind shear vanishes (\\(U_z \to 0\\)), causing raw Richardson numbers to blow up (\\(Ri_g \to \infty\\)). The engine evaluates the **Fold Ratio**:
   \\[\text{Fold Ratio} = \frac{|C_{\text{mapping}}|}{|C_{\text{constitutive}}| + |C_{\text{mapping}}|}\\]
   A Fold Ratio exceeding \\(0.99\\) flags a coordinate projection singularity ("Fold Illusion") where visual knees in physical space are driven entirely by mapping curvature rather than an actual physical collapse of the turbulent manifold.

4. **Preserving Physics: The High-Smoothing Flag (\\(\eta > 3.0\\))**
   The script compares the baseline Tikhonov parameters against the IRLS-refined parameters to calculate the downstream smoothing ratio \\(\eta = \alpha_{\text{downstream}} / \alpha_{\text{baseline}}\\). If \\(\eta > 3.0\\) for either potential temperature or wind speed, the column is flagged as *High-Smoothing / Intermittency Suspect* to ensure that numerical noise suppression does not accidentally erase genuine physical signals (e.g., intermittent mixing or gravity waves).

### High-Throughput Production Optimizations

$$\Sigma_s = A^{-1} W A^{-1} \implies \text{fact} \setminus (W \cdot (\text{fact} \setminus I))$$

This eliminates explicit matrix inversion (`inv(A)`), improving numerical stability on dense vertical grids ($N > 50$).
