The heatmap visualization infrastructure in **`SBLToolkit.jl`** consists of two primary Julia engines designed to map spatial-temporal boundary layer structures: **`plot_obukhov_heatmaps.jl`** (for multi-campaign Obukhov stability comparisons) and **`gspt_curvature_contour_v3.jl`** (for 2D differential-geometric curvature diagnostics).

---

### 1. Standardized Obukhov Heatmap Engine (`plot_obukhov_heatmaps.jl`)

To compare atmospheric stability across heterogeneous field campaigns (e.g., CASES-99, GABLS3, BLLAST, FLOSS-II, and SHEBA), the toolkit standardizes all soundings onto a uniform vertical grid spanning \(z \in\text{ m}\) at \(1\text{ m}\) resolution (`COMMON_Z_GRID = 1.0:1.0:100.0`).

#### **A. The 4-Panel Diagnostic Layout**

Each campaign execution produces a synchronized \(2 \times 2\) panel heatmap:

1. **Reciprocal Obukhov Length (\(1/L(z,t)\) \([m^{-1}]\)):**
   * **Purpose:** Quantifies buoyant flux scaling with height.
   * **Visualization:** Uses a symmetric red-white-blue colormap (`:coolwarm`/`:bwr`) clipped to \([-0.05, 0.05]\text{ m}^{-1}\). Positive values indicate stable stratification; negative values indicate convective instability.
2. **Symmetric-Log Stability Parameter (\(\zeta(z,t)\)):**
   * **Purpose:** Displays the dimensionless height ratio \(\zeta = z/L(z)\).
   * **Transformation:** Applies a symmetric log transform to resolve near-surface transitions alongside hyper-stable aloft regimes:
     \[\text{sgn}(\zeta) \log_{10}(1 + |\zeta|)\]
   * **Visualization:** Rendered using a Purple-White-Orange palette (`:puor`) bounded between \([-1.5, 1.5]\).
3. **Coordinate Jacobian (\(\zeta_z = \partial\zeta/\partial z\) \([m^{-1}]\)):**
   * **Purpose:** Maps vertical coordinate compression and stretching.
   * **Feature Overlay:** Superimposes a **solid white contour line** at \(\zeta_z = 0\) to explicitly trace spatial coordinate fold loci.
4. **Coordinate Curvature (\(\zeta_{zz} = \partial^2\zeta/\partial z^2\) \([m^{-2}]\)):**
   * **Purpose:** Identifies internal shear boundaries, inversion capping heights, and turbulent-to-laminar transition layers.

#### **B. Data Pipeline & Grid Interpolation Logic**

To ingest diverse tower footprints without introducing extrapolation noise, the code implements a two-pass matching and interpolation sequence:

* **1D Vertical Interpolation (`interpolate_profile_1d`):** Takes raw observations at discrete tower heights \(z_{\text{raw}}\) and interpolates them onto `COMMON_Z_GRID` using piecewise linear interpolation. Profiles with fewer than 2 valid levels are safely assigned `NaN` arrays to prevent unconstrained extrapolation.
* **\(Ri_g \to \zeta\) Mapping (`rig_to_zeta`):** Converts gradient Richardson number profiles to Monin–Obukhov coordinates while enforcing a safety cap (\(Ri_g \le 0.19\)) to prevent division-by-zero singularities near the critical Richardson number (\(Ri_c \approx 0.20\)):
  \[\zeta = \frac{Ri_g}{1 - 5 Ri_g} \qquad (Ri_g < 0.20)\]
* **Fallback Ingestion (`load_profile_from_nc`):** If trajectory CSVs are missing, the script uses `NCDatasets` to parse NetCDF files directly, extracting friction velocity (\(u_*\)) and surface heat flux (\(H_s\)) to construct Obukhov profiles.

### 2. GSPT Curvature Decomposition Engine (`gspt_curvature_contour_v3.jl`)

To separate true thermodynamic changes from spatial coordinate stretching, this module decomposes observed profile curvature using the exact GSPT chain-rule partition:
\[Ri_{zz} = \underbrace{R''(\zeta) \zeta_z^2}_{C_{\text{const}}} + \underbrace{R'(\zeta) \zeta_{zz}}_{C_{\text{coord}}} + \mathcal{E}_{\Delta z} \tag{decomposition}\]

#### **A. 6-Panel Diagnostic Panel Layout**

The visualization arranges six synchronized subplots (\(2 \times 3\) grid) across a 12-hour nocturnal cooling cycle:

| Row | Left Panel | Center Panel | Right Panel |
| :--- | :--- | :--- | :--- |
| **Top** | Stability Coordinate \(\zeta(z,t)\) | Analytical Richardson \(Ri(z,t)\) | Noisy Observed \(Ri_{\text{obs}}(z,t)\) |
| **Bottom** | Intrinsic Curvature \(C_{\text{const}}(z,t)\) | Coordinate Curvature \(C_{\text{coord}}(z,t)\) | Audit Residual \(\mathcal{E}_{\Delta z}(z,t)\) |

#### **B. Core Numerical Operators**

1. **Non-Uniform Finite-Difference Stencils (\(\mathbf{D}_1, \mathbf{D}_2\)):**
   Because tower levels (e.g., CASES-99 \(z \in [1.5, 5.0, 10.0, 20.0, 30.0, 45.0, 55.0]\text{ m}\)) are irregularly spaced, standard uniform finite differences fail. The script computes level-specific weights by solving local Taylor-Vandermonde linear systems (\(\mathbf{A w} = \mathbf{b}\)) for \(1\text{st}\) derivative (\(\mathbf{D}_1\)) and \(2\text{nd}\) derivative (\(\mathbf{D}_2\)) operators:
   \[A_{k,j} = \frac{(z_j - z_0)^{k-1}}{(k-1)!}, \quad b_{m+1} = 1.0 \implies \mathbf{w} = \mathbf{A}^{-1} \mathbf{b}\]
   Boundary levels utilize asymmetric 3-point one-sided stencils to guarantee second-order convergence across all heights.

2. **Track A Tikhonov Pre-Conditioning:**
   To prevent continuous Gaussian sensor noise (\(\sigma_{\text{obs}} = 0.008\)) from exploding under second differentiation, the script applies a Tikhonov regularization filter:
   \[\left(\mathbf{I} + \lambda_{\text{reg}} \mathbf{D}_2^T \mathbf{D}_2\right) Ri_{\text{smooth}} = Ri_{\text{obs}}\]
   This filters out high-frequency observational jitter before computing \(\mathbf{D}_2 Ri_{\text{smooth}}\), ensuring that the audit residual \(\mathcal{E}_{\Delta z} = \mathbf{D}_2 Ri_{\text{smooth}} - Ri_{\text{exact}}\) cleanly isolates grid discretization errors rather than sensor noise.

### 3. Key Visual Insights Revealed by the Heatmaps

* **Inflection Masking Illusion (\(z \approx 10\text{ m}\)):** The bottom-left (\(C_{\text{const}}\)) and bottom-center (\(C_{\text{coord}}\)) panels demonstrate that positive coordinate curvature (\(C_{\text{coord}} \approx +0.0036\text{ m}^{-2}\)) actively cancels negative stability curvature (\(C_{\text{const}} \approx -0.0040\text{ m}^{-2}\)) during deep stable hours. The resulting locally linear profile (\(Ri_{zz} \approx -0.0004\text{ m}^{-2}\)) masks these active, offsetting physical processes.
* **Jet Nose "Fold Illusion" (\(z \approx 45\text{ m}\)):** Near Low-Level Jet (LLJ) cores where vertical wind shear vanishes (\(S^2 \to 0\)), \(C_{\text{coord}}\) spikes strongly positive. The heatmap shows that over 99.4% of the visual "profile knee" observed aloft is pure coordinate-stretching geometry rather than a physical turbulence extinction event.

**3. Primary Physical Diagnostic Takeaways**

* **Inflection Masking ($z \approx 10 \text{ m}$)**: Positive coordinate curvature ($C_{\text{coord}} \approx +0.0036 \text{ m}^{-2}$) cancels negative stability curvature ($C_{\text{const}} \approx -0.0040 \text{ m}^{-2}$), hiding active, opposing physical mechanisms behind an apparently linear profile ($Ri_{zz} \approx 0$).

Implementing these refactorings will eliminate visual artifacts, prevent numerical crashes on sparse grids, and align the script with **Generalized Similarity Profile Theory (GSPT)**.

---

### 1. Mathematical & Physical Enhancements

1. **Replace Businger–Dyer \(Ri_g \to \zeta\) Inversion with Non-Singular Closures:**
   * _Current Code:_ `rig_to_zeta` uses the standard rational map \(\zeta = Ri_g / (1 - 5 Ri_g)\) with a hard ceiling `rig_c = min(rig, 0.19)`.
   * _Problem:_ Under strong nocturnal stability (\(Ri_g \ge 0.20\)), this hard cap flatlines \(\zeta\), artificially truncating hyper-stable boundary layer structure.
   * _Solution:_ Integrate the SHEBA-calibrated **Grachev et al. (2007) / GLGS (eMOST)** formulation or **Zero-Offset Hyperbolic Regularization (Z0HR)**:
     \[\phi_m(\zeta) = 1 + \frac{a_m \zeta}{(1 + b_m \zeta)^{2/3}}, \quad \phi_h(\zeta) = Pr_0 \left(1 + \frac{a_h \zeta}{1 + b_h \zeta}\right) \tag{GLGS}\]
     This provides a continuous, non-singular mapping across extreme stability regimes (\(\zeta \in\)) without artificial threshold clipping.

2. **Integrate Full GSPT Curvature Partitioning (\(C_{\text{const}}\) vs. \(C_{\text{coord}}\)):**
   * _Current Code:_ The fourth heatmap panel only plots total coordinate curvature (\(\zeta_{zz}\)).
   * _Solution:_ Expand or option-toggle Panel 4 to decompose physical Richardson curvature into constitutive and mapping components:
     \[\frac{d^2 Ri_g}{dz^2} = \underbrace{R''(\zeta)\zeta_z^2}_{C_{\text{const}}} + \underbrace{R'(\zeta)\zeta_{zz}}_{C_{\text{coord}}} + \mathcal{E}_{\Delta z} \tag{Curvature Partition}\]
     This explicitly unmasks **Inflection Masking** near the surface (\(z \approx 10\text{ m}\), where \(C_{\text{coord}} \approx -C_{\text{const}}\)) and **Fold Illusions** near Low-Level Jet noses (\(z \approx 30\text{--}45\text{ m}\), where \(C_{\text{coord}}\) dominates).

---

### 2. Numerical & Algorithmic Optimizations

1. **Fix the "Piecewise-Linear Hessian Zeroing" Artifact:**
   * _Current Bug:_ `assemble_derivatives_from_zeta` first linearly interpolates \(\zeta\) onto `COMMON_Z_GRID` (1-meter spacing) using `interpolate_profile_1d`, and then calls `uniform_hessian_1d`.
   * _Consequence:_ Piecewise-linear interpolation forces the second vertical derivative (\(\zeta_{zz}\)) to be **zero everywhere except at the native discrete sensor nodes**! This produces horizontal "banded" line artifacts rather than continuous spatial curvature fields.
   * _Fix (Track A Regularization):_ Construct non-uniform derivative operators (\(\mathbf{D}_1, \mathbf{D}_2\)) on the **native** tower grid _before_ interpolating, or fit a natural cubic smoothing spline in log-height space (\(\xi = \ln(z/z_0)\)) under Morozov's Discrepancy Principle. Differentiate the continuous spline analytically, then project the smooth derivative fields onto `COMMON_Z_GRID`.

2. **Enforce the \(N_z \ge 3\) Stencil Gate & SHEBA Bulk Fallback:**
   * _Current Code:_ The script attempts to evaluate 3-point stencil gradients on all campaign files regardless of vertical level count.
   * _Problem:_ In two-level campaigns like **SHEBA** (\(N_z = 2\): \(2.5\text{ m}, 10\text{ m}\)), spatial derivative operators collapse under-determinately, leaving empty/all-NaN Hessian heatmaps.
   * _Fix:_ Enforce the mandatory ingestion check (\(N_z \ge 3\)). For \(N_z < 3\), flag as `STENCIL_DEGRADED` / `Bypassed Guard` and route to the **Bulk Richardson (\(Ri_b\)) fallback engine** (`SHEBABulkFallback`) with regularized exchange floors (\(K_m \ge 0.10, K_h \ge 0.015\text{ m}^2/\text{s}\)).

3. **Allocation-Free Inner Loops via `SplineWorkspace` Caching:**
   * _Problem:_ Calling `fill(NaN, ...)` and array slicing inside `for j in 1:nt` triggers heavy garbage collection overhead across seasonal datasets (\(N_t > 10^4\)).
   * _Fix:_ Pre-allocate output matrices (`zeta_mat`, `zeta_z_mat`, `zeta_zz_mat`, `inv_L_mat`) outside the timestep loop and reuse a thread-safe `SplineWorkspace` struct.

---

### 3. Visual & Aesthetic Enhancements

1. **Logarithmic / Non-Linear Height Scaling (\(z\)-axis):**
   * Linear vertical scaling (\(1.0:1.0:100.0\text{ m}\)) squashes the lowest \(10\text{ m}\) where surface heat fluxes and gradient inversions are steepest.
   * _Fix:_ Add logarithmic tick spacing (`yticks = (, ...)`) to give equal visual weight to near-surface constant-flux processes and elevated jet shear layers.

2. **Time Axis Standardization:**
   * In several dataset parsers, raw sample indices or epoch seconds are plotted directly (e.g., FLOSS-II displaying \(1.0 \times 10^4 \dots 7.0 \times 10^4\) on the x-axis).
   * _Fix:_ Normalize time axes across all campaign plots to **Diurnal Hours (0–24 UTC)** or local solar time.

3. **Safe Zero-Contour Overlays:**
   * Wrap `contour!(p3, ...)` in a defensive guard to prevent GR backend exceptions when missing daytime convective blocks or sentinel gaps occur.

```julia
# =============================================================================
# REFACTORED TRACK A DERIVATIVE ENGINE FOR PLOT_OBUKHOV_HEATMAPS.JL
# =============================================================================
using LinearAlgebra, Statistics

"""
    assemble_derivatives_track_a(timestamps, raw_z_levels, raw_zeta_mat; sigma_obs=0.01)

Constructs smooth vertical derivatives on native tower heights prior to 1D grid
interpolation, avoiding piecewise-linear Hessian zeroing artifacts.
"""
function assemble_derivatives_track_a(
    timestamps::Vector{Float64},
    raw_z_levels::Vector{Float64},
    raw_zeta_mat::Matrix{Float64};
    sigma_obs::Float64 = 0.01
)
    nt = length(timestamps)
    nz_raw = length(raw_z_levels)

    # 1. Enforce Mandatory Stencil Gate (Nz >= 3)
    if nz_raw < 3
        @warn "Stencil collapse gate triggered (Nz = $nz_raw < 3). Routing to Bulk Richardson Fallback."
        return assemble_bulk_fallback(timestamps, raw_z_levels, raw_zeta_mat)
    end

    z_target = COMMON_Z_GRID
    nz_target = length(z_target)

    # 2. Build non-uniform Taylor-Vandermonde derivative operators on NATIVE grid
    D1_native, D2_native = build_operators(raw_z_levels) # Non-uniform stencil matrix

    # 3. Pre-allocate Output Matrices
    zeta_mat    = fill(NaN, nz_target, nt)
    zeta_z_mat  = fill(NaN, nz_target, nt)
    zeta_zz_mat = fill(NaN, nz_target, nt)
    inv_L_mat   = fill(NaN, nz_target, nt)

    # Reusable scratch buffers for zero-allocation inner loop
    raw_z_z  = zeros(nz_raw)
    raw_z_zz = zeros(nz_raw)

    @inbounds for j in 1:nt
        raw_zeta = raw_zeta_mat[:, j]
        valid_idx = findall(isfinite, raw_zeta)

        if length(valid_idx) >= 3
            # Compute derivatives on native irregular grid BEFORE spatial interpolation
            raw_z_z  .= D1_native * raw_zeta
            raw_z_zz .= D2_native * raw_zeta

            # Interpolate smooth native profiles onto standard COMMON_Z_GRID
            zeta_mat[:, j]    = interpolate_profile_1d(raw_zeta, raw_z_levels, z_target)
            zeta_z_mat[:, j]  = interpolate_profile_1d(raw_z_z, raw_z_levels, z_target)
            zeta_zz_mat[:, j] = interpolate_profile_1d(raw_z_zz, raw_z_levels, z_target)

            for i in 1:nz_target
                if isfinite(zeta_mat[i, j])
                    inv_L_mat[i, j] = zeta_mat[i, j] / z_target[i]
                end
            end
        end
    end

    return (
        timestamps = timestamps,
        z_levels   = z_target,
        inv_L      = inv_L_mat,
        zeta       = zeta_mat,
        zeta_z     = zeta_z_mat,
        zeta_zz    = zeta_zz_mat
    )
end
```
