**Morozov’s Discrepancy Principle (MDP)** is a mathematical parameter choice rule designed to determine the optimal regularization parameter in ill-posed inverse problems. In computational modeling and observational geophysics, it is widely utilized to balance model fidelity against noise amplification when reconstructing physical fields from noisy, discrete measurements.

By examining its rigorous mathematical formulation, the unique challenges of non-linear inversions, and its direct application to **Generalized Similarity Profile Theory (GSPT)** for boundary-layer meteorology, we can understand how MDP operates as a foundational computational tool.

---

### 1. Mathematical Foundations of Morozov’s Discrepancy Principle

An inverse problem is often modeled as an operator equation:
\\[F(x) = y\\]
where \\(F: X \to Y\\) is an operator between Banach spaces, and \\(y^\delta\\) represents the noisy, observed data with a known noise level \\(\delta\\) such that \\(\|y^\delta - y\|_Y \le \delta\\). To solve this stably, **Tikhonov regularization** is applied to minimize the functional:
\\[\min_{x \in X} \left\{ \frac{1}{2} \|F(x) - y^\delta\|_Y^2 + \alpha R(x) \right\}\\]
where \\(\alpha > 0\\) is the regularization parameter, and \\(R(x)\\) is a convex penalty term (such as an \\(\ell_1\\) or \\(\ell_2\\) norm).

#### The Parameter Choice Rule
The classical Morozov's Discrepancy Principle asserts that the regularization parameter \\(\alpha = \alpha(\delta, y^\delta)\\) should be selected such that the residual norm (discrepancy) of the regularized solution \\(x_\alpha^\delta\\) matches the noise level of the data:
\\[\tau_1 \delta \le \|F(x_\alpha^\delta) - y^\delta\|_Y \le \tau_2 \delta\\]
where \\(1 \le \tau_1 < \tau_2\\). Physically, this means **we should not fit the regularized solution more closely to the data than the noise level of the measurements themselves**.

#### The Non-Linear Existence Challenge
*   **Linear Inverse Problems:** If the operator \\(F\\) is linear, the discrepancy function \\(\|F(x_\alpha^\delta) - y^\delta\|_Y\\) is monotonically increasing and strictly continuous with respect to \\(\alpha\\). Under these conditions, the existence of a parameter \\(\alpha\\) satisfying the discrepancy principle is mathematically guaranteed.
*   **Non-Linear Inverse Problems:** When \\(F\\) is a non-linear operator, the Tikhonov functional can possess multiple local minimizers. Consequently, the discrepancy function is **not continuous** and can exhibit sudden jump discontinuities as a function of \\(\alpha\\). If a jump occurs across the target interval \\([\tau_1 \delta, \tau_2 \delta]\\), **no regularization parameter \\(\alpha\\) exists that satisfies the classical discrepancy principle**.

#### The Modified MDP and Tangential Cone Condition
To resolve this non-linear discontinuity issue, researchers assume a **tangential cone condition** on the non-linear operator \\(F\\):
\\[\|F(x_2) - F(x_1) - F'(x_1)(x_2 - x_1)\|_Y \le \gamma \|F(x_2) - F(x_1)\|_Y \quad \forall x_1, x_2 \in L_\alpha^\delta\\]
where \\(\gamma > 0\\) is a structural constant, and \\(L_\alpha^\delta\\) is the set of minimizers.

Under this condition, we can prove the existence of at least one regularization parameter \\(\alpha\\) by widening the upper bound via a **Modified Morozov's Discrepancy Principle**:
\\[\tau_1 \delta \le \|F(x_\alpha^\delta) - y^\delta\|_Y \le c \delta, \quad \text{where } c = \max\{\tau_2, (3 + 2\gamma)\tau_1\}\\]
This guarantees the existence of an optimal \\(\alpha\\) provided that the upper-bound tolerance is relaxed to \\(\tau_2 \ge (3+2\gamma)\tau_1\\). As the noise level vanishes (\\(\delta \to 0\\)), the parameter converges strictly to zero (\\(\alpha \to 0\\)), and the regularized solution \\(x_\alpha^\delta\\) converges to the exact minimum-norm solution.

In numerical practice, algorithms like **Algorithm 1** (a soft-thresholding bisection search) are employed to dynamically resolve \\(\alpha\\). Simulations across non-linear compressive sensing and 1D gravity anomaly inversions demonstrate that using the discrepancy principle with Algorithm 1 dramatically reduces reconstruction relative errors.

### 2. Meteorological Application: Noise Regularization in GSPT

The mathematical utility of Morozov's Discrepancy Principle is directly illustrated in **Generalized Similarity Profile Theory (GSPT)** when processing multi-level boundary-layer tower observations.

```
Raw Tower Data (Ri_obs) ──► [ Asymmetric Grid Finite-Differences ] ──► Severe Noise Amplification (E_Δz)
                                         │
                    Tikhonov Regularization (Roughness Penalty R)
                                         │
                 Morozov's Discrepancy Principle (Optimal λ)
                                         │
                                         ▼
                     Smoothed, Physically Continuous Profile
```

#### The Noise Amplification Problem
When calculating the vertical gradient (\\(\partial Ri/\partial z\\)) and curvature (\\(\partial^2 Ri/\partial z^2\\)) over Irregular Tower Networks (such as the CASES-99 tower where heights span \\(z \in [1.5, 55]\text{ m}\\)), naive finite-difference stencils severely amplify high-frequency measurement noise. Widening a centered stencil from 3 to 5 points to reduce truncation error actually increases the noise propagation factor by approximately 76% due to lopsided grid gaps.

Unregularized stencils yield spurious curvature spikes, masking the underlying physics and misinterpreting noise as physical turbulence state transitions.

#### The GSPT Regularized Operator
To isolate continuous physical derivatives from this observational noise, GSPT formulates a non-dimensional Tikhonov regularization pipeline:
1.  **Nondimensionalization:** Physical heights are normalized by the boundary-layer height scale (\\(\tilde{z} = z/H_{\text{SBL}}\\)), which ensures the stencil operator remains \\(\tilde{D}_2 \sim \mathcal{O}(1)\\) and bounds the discrete roughness matrix \\(R_{\tilde{z}} = D_{\tilde{z},2}^\top D_{\tilde{z},2}\\).
2.  **Regularization Tuning via Morozov:** The dimensionless regularizing parameter \\(\tilde{\lambda}\\) is uniquely selected using Morozov’s Discrepancy Principle by matching the residual norm of the smoothed profile directly to the known standard deviation (\\(\sigma_{\text{obs}}\\)) of the sonic anemometers:
    \\[\|Ri_{\text{smooth}} - Ri_{\text{obs}}\|^2 \approx N \sigma_{\text{obs}}^2\\]
    where \\(N\\) is the number of irregular tower levels.

#### Physical Significance
By tying the smoothing penalty \\(\tilde{\lambda}\\) directly to the instrument noise floor, **Morozov tuning prevents the regularized operator from over-smoothing genuine physical structures or regularizing into noise**.

This allows GSPT to cleanly resolve the sub-surface **inflection masking zone** (\\(z \approx 10\text{ m}\\)), where coordinate stretching balances intrinsic thermodynamic curvature (\\(\mathcal{R}_{\text{coord}} \approx -1.0\\)), as well as the **coordinate fold singularity** (\\(z \approx 45\text{ m}\\)) near the Low-Level Jet axis. Bypassing these coordinate projection artifacts is strictly required to identify the true physical relaminarization transitions of the nocturnal stable boundary layer.

# --- 2. Stencil & Operator Utilities ---
function stencil_weights(z_stencil::Vector{Float64}, z0::Float64, m::Int)
    p = length(z_stencil)
    A = [(z - z0)^(k - 1) / factorial(k - 1) for k in 1:p, z in z_stencil]
    b = zeros(p); b[m + 1] = 1.0
    return A \ b
end

function build_operators(z::Vector{Float64})
    n = length(z)
    D1, D2 = zeros(n, n), zeros(n, n)
    for i in 2:n-1
        idx = [i-1, i, i+1]
        D1[i, idx] .= stencil_weights(z[idx], z[i], 1)
        D2[i, idx] .= stencil_weights(z[idx], z[i], 2)
    end
    D1[1, 1:3] .= stencil_weights(z[1:3], z[1], 1)
    D2[1, 1:3] .= stencil_weights(z[1:3], z[1], 2)
    D1[n, n-2:n] .= stencil_weights(z[n-2:n], z[n], 1)
    D2[n, n-2:n] .= stencil_weights(z[n-2:n], z[n], 2)
    return D1, D2
end

function solve_morozov(y_obs::Vector{Float64}, R_tilde::Matrix{Float64}, σ::Float64)
    n = length(y_obs)
    σ == 0.0 && return copy(y_obs)
    target = n * (σ^2)
    λ_grid = 10.0 .^ range(-10, 2, length=2000)
    best_λ = λ_grid[1]
    min_diff = Inf

    for λ in λ_grid
        y_s = (I(n) + λ .* R_tilde) \ y_obs
        res = sum((y_s .- y_obs).^2)
        diff = abs(res - target)
        if diff < min_diff
            min_diff = diff
            best_λ = λ
        end
    end
    return (I(n) + best_λ .* R_tilde) \ y_obs
end

# --- 3. Tangential Cone Condition Evaluator ---
function check_tangential_cone(x1::Vector{Float64}, x2::Vector{Float64}, g::Float64, theta0::Float64, D1::Matrix{Float64})
    # Forward map F maps profile state x = [u; v; theta_v] to Ri profile
    n = length(x1) ÷ 3
    eval_F(x) = begin
        u, v, th = x[1:n], x[n+1:2*n], x[2*n+1:3*n]
        du = D1 * u; dv = D1 * v; dth = D1 * th
        S2 = max.((du.^2) .+ (dv.^2), 1e-6)
        return (g ./ theta0) .* dth ./ S2
    end

    F1 = eval_F(x1)
    F2 = eval_F(x2)

    # Numerical Jacobian calculation for F'(x1)
    eps_j = 1e-6
    J = zeros(n, 3*n)
    for j in 1:3*n
        x_plus = copy(x1); x_plus[j] += eps_j
        J[:, j] = (eval_F(x_plus) .- F1) ./ eps_j
    end

    dx = x2 .- x1
    linear_approx = F1 .+ J * dx

    denom = norm(F2 .- F1)
    denom == 0.0 && return 0.0
    gamma = norm(F2 .- linear_approx) / denom
    return gamma
end

# --- 4. Independent Triple-Point Diagnostic ---
function compute_c_tp(z::Vector{Float64}, tke::Vector{Float64}, Km::Vector{Float64},
                       D1::Matrix{Float64}; tke_fraction::Float64=0.05)
    H_SBL = maximum(z)

    e_min = minimum(tke) + tke_fraction * (maximum(tke) - minimum(tke))
    idx_e = findfirst(e -> e <= e_min, tke)
    z_e = isnothing(idx_e) ? z[end] : z[idx_e]

    de_dz = abs.(D1 * tke)
    z_ez = z[argmax(de_dz)]

    Km_min = minimum(Km) + tke_fraction * (maximum(Km) - minimum(Km))
    idx_K = findfirst(K -> K <= Km_min, Km)
    z_K = isnothing(idx_K) ? z[end] : z[idx_K]

    pts = [z_e, z_ez, z_K]
    return (maximum(pts) - minimum(pts)) / H_SBL
end

# --- 5. Core Computation Engine ---
function compute_gspt(data::ProfileData; β_m=1.0, β_h=3.0, eps_C=1e-5, S2_min=1e-4,
                      is_observation=false, tke_fraction=0.05)
    z = data.z
    n = length(z)
    g, κ = 9.81, 0.40
    H_SBL = maximum(z)

    D1_dim, D2_dim = build_operators(z)
    _, D2_tilde = build_operators(z ./ H_SBL)
    R_tilde = D2_tilde' * D2_tilde

    # Calculate grid operator condition number κ(R_tilde)
    eigs = eigvals(R_tilde)
    valid_eigs = filter(e -> e > 1e-12, eigs)
    grid_cond_number = length(valid_eigs) > 0 ? maximum(valid_eigs) / minimum(valid_eigs) : Inf

    # Track A: Primitive Field Regularization (Primary MDP Track)
    u_eval = is_observation ? solve_morozov(data.u, R_tilde, data.sigma_u) : copy(data.u)
    v_eval = is_observation ? solve_morozov(data.v, R_tilde, data.sigma_v) : copy(data.v)
    th_eval = is_observation ? solve_morozov(data.theta_v, R_tilde, data.sigma_theta) : copy(data.theta_v)

    du_dz = D1_dim * u_eval
    dv_dz = D1_dim * v_eval
    dth_dz = D1_dim * th_eval

    S2 = (du_dz.^2) .+ (dv_dz.^2)
    ill_conditioned_mask = S2 .<= S2_min
    S2_bounded = max.(S2, S2_min)

    Ri_obs_field = (g ./ th_eval) .* dth_dz ./ S2_bounded
    Ri_zz_obs_field = D2_dim * Ri_obs_field

    # Track B: Diagnostic-Space Regularization (Sensitivity Benchmark)
    du_raw = D1_dim * data.u; dv_raw = D1_dim * data.v; dth_raw = D1_dim * data.theta_v
    S2_raw = max.((du_raw.^2) .+ (dv_raw.^2), S2_min)
    Ri_raw = (g ./ data.theta_v) .* dth_raw ./ S2_raw
    Ri_obs_diag = is_observation && data.sigma_ri_diag > 0.0 ? solve_morozov(Ri_raw, R_tilde, data.sigma_ri_diag) : copy(Ri_raw)
    Ri_zz_obs_diag = D2_dim * Ri_obs_diag

    tau_reg_sens = Ri_zz_obs_field .- Ri_zz_obs_diag

    # Obukhov Length L(z)
    ustar = ((data.uw .^ 2) .+ (data.vw .^ 2)) .^ 0.25
    L = zeros(n)
    for i in 1:n
        flux = data.wthv[i]
        L[i] = abs(flux) > 1e-6 ? -(ustar[i]^3 * th_eval[i]) / (κ * g * flux) : 1e5
    end

    # Coordinate Geometry
    zeta = z ./ L
    zeta_z = D1_dim * zeta
    zeta_zz = D2_dim * zeta
    coord_geom = CoordinateGeometry(zeta, zeta_z, zeta_zz)

    # Analytic Parameterization
    Ri_func(ζ)    = ζ * (1.0 + β_h * ζ) / ((1.0 + β_m * ζ)^2)
    Ri_z_func(ζ)  = (1.0 + (2.0 * β_h - β_m) * ζ) / ((1.0 + β_m * ζ)^3)
    Ri_zz_func(ζ) = (2.0 * β_h - 4.0 * β_m + 2.0 * β_m * (β_m - 2.0 * β_h) * ζ) / ((1.0 + β_m * ζ)^4)

    Ri_gspt_val    = Ri_func.(zeta)
    Ri_z_gspt_val  = Ri_z_func.(zeta)
    Ri_zz_gspt_val = Ri_zz_func.(zeta)

    C_const = Ri_zz_gspt_val .* (zeta_z .^ 2)
    C_coord = Ri_z_gspt_val .* zeta_zz
    Ri_zz_chain_rule = C_const .+ C_coord

    R_coord = [abs(C_const[i]) > eps_C && !ill_conditioned_mask[i] ? C_coord[i] / C_const[i] : NaN for i in 1:n]
    const_geom = ConstitutiveGeometry(Ri_gspt_val, Ri_z_gspt_val, Ri_zz_chain_rule, C_const, C_coord, R_coord)

    closure_residual = Ri_zz_obs_field .- Ri_zz_chain_rule
    tau_truncation = (D2_dim * Ri_gspt_val) .- Ri_zz_chain_rule

    obs_diag = ObservationDiagnostic(Ri_obs_field, Ri_zz_obs_field, tau_truncation,
                                     tau_reg_sens, closure_residual, ill_conditioned_mask, grid_cond_number)

    C_TP = compute_c_tp(z, data.tke, data.Km, D1_dim; tke_fraction=tke_fraction)

    return DiagnosticResult(z, L, coord_geom, const_geom, obs_diag, C_TP)
end

# --- 6. Multi-Track Comparison ---
function compare_tracks(obs::DiagnosticResult, scm::DiagnosticResult, les::DiagnosticResult;
                        eps_mask=0.15)
    n = length(obs.z)

    calc_mask_frac(R_vec) = begin
        v = filter(!isnan, R_vec)
        length(v) > 0 ? count(r -> abs(r + 1.0) < eps_mask, v) / length(v) : 0.0
    end

    frac_obs = calc_mask_frac(obs.const_geom.R_coord)
    frac_scm = calc_mask_frac(scm.const_geom.R_coord)
    frac_les = calc_mask_frac(les.const_geom.R_coord)

    mask_scm = .!isnan.(obs.const_geom.R_coord) .& .!isnan.(scm.const_geom.R_coord)
    mask_les = .!isnan.(obs.const_geom.R_coord) .& .!isnan.(les.const_geom.R_coord)

    bias_R_scm = fill(NaN, n)
    bias_R_les = fill(NaN, n)

    bias_R_scm[mask_scm] .= scm.const_geom.R_coord[mask_scm] .- obs.const_geom.R_coord[mask_scm]
    bias_R_les[mask_les] .= les.const_geom.R_coord[mask_les] .- obs.const_geom.R_coord[mask_les]

# In src/GSPTPhase2.jl -> solve_morozov()
function solve_morozov(y_obs::Vector{Float64}, R_tilde::Matrix{Float64}, σ::Float64)
    n = length(y_obs)
    σ == 0.0 && return copy(y_obs)
    target = n * (σ^2)

    # Stabilize matrix conditioning for inversion
    R_stable = R_tilde + 1e-8 * I(n)

    λ_grid = 10.0 .^ range(-8, 2, length=2000)
    best_λ = λ_grid[1]
    min_diff = Inf

    for λ in λ_grid
        y_s = (I(n) + λ .* R_stable) \ y_obs
        res = sum((y_s .- y_obs).^2)
        diff = abs(res - target)
        if diff < min_diff
            min_diff = diff
            best_λ = λ
        end
    end
    return (I(n) + best_λ .* R_stable) \ y_obs
end

using LinearAlgebra, SparseArrays

function smooth_profile(obs::Vector{T}, λ::T) where {T<:AbstractFloat}
    n = length(obs)
    # Discrete 2nd-difference operator matrix D2
    D2 = spdiagm(-1 => ones(T, n-1), 0 => -2*ones(T, n), 1 => ones(T, n-1))[2:n-1, :]

    # Regularized implicit system: (I + λ D2ᵀ D2) x = obs
    A = I + λ * (D2' * D2)
    return A \ obs
end

### Critique of the "Transition Heatmaps" Framework

While the original **"Transition Heatmaps"** methodology offers a solid conceptual foundation for mapping stable boundary layer (SBL) transitions using the dynamic metric \\(R_{\text{coord}}(z, t)\\), it exhibits several critical scientific and mathematical limitations that must be addressed to make it a rigorous, publication-grade analytical tool:

1. **Noise Amplification vs. Over-Smoothing (The Differentiation Dilemma):**
   Calculating first and second vertical derivatives (\\(\partial / \partial z\\) and \\(\partial^2 / \partial z^2\\)) of noisy state profiles (wind speed and potential temperature) is an ill-posed inverse problem. Naive finite differences catastrophically amplify high-frequency sensor noise. Conversely, arbitrary spline or ad-hoc Gaussian smoothing erases physically real curvature, flattens Low-Level Jet (LLJ) noses, and falsely thickens sharp inversion layers. The original heatmaps lack a systematic, noise-bounded filter.
2. **Conflating Spurious Gradients with Physical Transitions (Track B Failure):**
   The original pipeline applies smoothing directly to the computed Richardson number (\\(Ri\\)) profile (Track B). Near the nose of an LLJ, vertical wind shear vanishes (\\(S^2 \to 0\\)), causing \\(Ri \to \infty\\). Direct smoothing over this quotient singularity propagates massive, non-physical numerical spikes into adjacent layers, corrupting the entire transition surface.
3. **The 5-Point Stencil Noise Penalty on Non-Uniform Grids:**
   The original model assumes that higher-order stencils improve accuracy. However, on non-uniform tower grids (e.g., CASES-99), a 5-point stencil is forced to pull in highly distant levels to cancel lower-order truncation terms. This asymmetric stretching generates unbalanced weights, yielding a noise propagation gain that is **76% larger** than a robust 3-point asymmetric centered stencil (\\(G_5 / G_3 \approx 1.76\\)).
4. **Lack of Inversion and Coordinate Validity Verification:**
   The original heatmap assumes the scalar coordinate mapping \\(\zeta = z/L\\) is universally invertible. It fails to audit where local Taylor series reversions break down as \\(Ri \to Ri_c \approx 0.25\\). Near the jet nose, coordinate compression dominates (\\(\zeta_z \to 0\\)), generating a "fold illusion" where a sharp profile "knee" is purely a projection artifact rather than true physical turbulence collapse.
5. **Mask Conflation and Zero-Padding Corruption:**
   The original plotting routine masks out ill-conditioned points but fails to distinguish between physically unavailable data, missing observations, failed sensor ingestion, and genuine GSPT singularities. Furthermore, the ingestion layer is highly vulnerable to zero-padding missing fluxes. Padding missing values with `0.0` (setting absolute zero temperatures or calm winds) introduces huge, spurious vertical gradients when differentiated.

using Test
using Statistics

"""
    compute_triple_point_dispersion(z, Km, e; alpha=0.05, e_ref=1.0)

Computes non-dimensional triple-point dispersion (δ_TP) for a single vertical profile column:
1. Diffusivity cutoff height z_K = argmin(K_m)
2. TKE level-set height z_e where e(z_e) ≈ α * e_ref
3. TKE gradient extremum height z_e_z = argmax(|∂e/∂z|)
"""
function compute_triple_point_dispersion(
    z::AbstractVector{<:Real},
    Km::AbstractVector{<:Real},
    e::AbstractVector{<:Real};
    alpha::Real = 0.05,
    e_ref::Real = 1.0
)
    # Filter out missing/NaN values prior to computation
    valid_mask = isfinite.(Km) .& isfinite.(e) .& isfinite.(z)
    if count(valid_mask) < 3
        return NaN
    end

    z_v  = z[valid_mask]
    Km_v = Km[valid_mask]
    e_v  = e[valid_mask]

    # 1. Diffusivity cutoff height
    z_K = z_v[argmin(Km_v)]

    # 2. TKE level-set height
    target_e = alpha * e_ref
    z_e = z_v[argmin(abs.(e_v .- target_e))]

    # 3. TKE gradient extremum height
    de_dz = abs.(diff(e_v) ./ diff(z_v))
    z_ez_mid = (z_v[1:end-1] .+ z_v[2:end]) ./ 2.0
    z_ez = z_ez_mid[argmax(de_dz)]

    # Domain height scaling factor
    H_sbl = maximum(z_v) - minimum(z_v)
    H_sbl > 0 || return NaN

    # Non-Dimensional Triple-Point Dispersion
    return (max(z_K, z_e, z_ez) - min(z_K, z_e, z_ez)) / H_sbl
end
