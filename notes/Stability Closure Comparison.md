```julia
#!/usr/bin/env julia
# sbl_closures.jl — Comparative modeling of SBL stability functions and exchange factors

using Printf

struct SBLModel
    Ri_c::Float64
    C_m::Float64
end

SBLModel(; Ri_c = 0.2, C_m = 5.0) = SBLModel(Ri_c, C_m)

# 1. Businger-Dyer Log-Linear (C⁰ kink at Ri_c)
Sm_businger(m::SBLModel, Ri) = max(0.0, 1.0 - (1.0 / m.Ri_c) * Ri)

# 2. Quadratic Pr = 1 Formulation (Smooth C¹ transition)
Sm_quadratic(m::SBLModel, Ri) = Ri >= m.Ri_c ? 0.0 : (1.0 - Ri / m.Ri_c)^2

# 3. SHEBA Empirical Similarity (Grachev et al., 2007)
phi_m_sheba(ζ) = 1.0 + (6.5 * ζ * (1.0 + ζ)^(1/3)) / (1.0 + 1.3 * ζ)

# 4. Energy and Flux Budget (EFB) Non-Extinguishing Asymptotic Closure
Sm_efb(m::SBLModel, Ri) = 1.0 / (1.0 + m.C_m * Ri)

function run_comparison()
    model = SBLModel()
    ri_range = 0.0:0.05:0.5

    println("Ri\t| Businger\t| Pr=1 Quad\t| EFB (Asymptotic)")
    println("-"^55)
    for Ri in ri_range
        @printf(
            "%.2f\t| %.4f\t| %.4f\t| %.4f\n",
            Ri,
            Sm_businger(model, Ri),
            Sm_quadratic(model, Ri),
            Sm_efb(model, Ri)
        )
    end
end

if abspath(PROGRAM_FILE) == @__FILE__
    run_comparison()
end

```

## Stability Closure Comparison

| Closure Schema | Governing Equation | Behavior at $Ri \ge Ri_c$ | Numerical Solver Impact |
| --- | --- | --- | --- |
| **Businger-Dyer (Legacy)** | $S_m = 1 - \frac{Ri}{Ri_c}$ | Hard extinction ($C^0$ kink) | Triggers spurious grid-scale oscillations |
| **Quadratic $Pr=1$** | $S_m = \left(1 - \frac{Ri}{Ri_c}\right)^2$ | Smooth collapse ($C^1$ continuity) | Eliminates derivative jump at $Ri = Ri_c$ |
| **SHEBA (Grachev '07)** | $\phi_m(\zeta) = 1 + \frac{6.5\zeta(1+\zeta)^{1/3}}{1+1.3\zeta}$ | Saturation to $z$-less limit | Matches multi-level tower flux measurements |
| **EFB Closure** | $S_m = \frac{1}{1 + C_m Ri}$ | Non-extinguishing ($S_m > 0$) | Supports residual mixing from LLJs aloft |

## Physical & Computational Highlights

* **Smoothing the Transition:** Standard log-linear functions impose an abrupt derivative discontinuity at $Ri = Ri_c$. Imposing $Pr = 1$ forces $\frac{\partial S_m}{\partial Ri} = 0$ as $Ri \to Ri_c$, stabilizing implicit time-stepping schemes in single-column models (SCMs).
* **Preventing Runaway Decoupling:** Legacy closures shut off turbulent exchange completely when $Ri > Ri_c$, causing unphysical surface cooling rates. EFB closures preserve an asymptotic tail ($S_m \sim Ri^{-1}$), correctly modeling Regime IV "upside-down" turbulence generated by shear aloft.
