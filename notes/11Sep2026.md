In Planetary Boundary Layer (PBL) parameterizations, **spurious quenching** (or false runaway decoupling) is driven by an unphysical positive feedback loop. This occurs when under-resolved spatial profile curvature or coordinate compression causes a discrete local Richardson number (\(Ri_g\)) to artificially cross the critical threshold (\(Ri_{\text{crit}} \approx 0.20 - 0.25\)), shutting off turbulent exchange and isolating the land surface.

---

### 1. The Physics of the Runaway Feedback Loop

When \(Ri_g\) crosses \(Ri_{\text{crit}}\), the parameterization initiates a destructive positive feedback cascade:

1. **Diffusivity Shutdown:** The local eddy diffusivity collapses (\(\mathcal{K}_h'(Ri_g) \ll 0\)), shutting off turbulent mixing.
2. **Heat Flux Collapse:** Downward sensible heat flux (\(H = -\rho c_p K_h \theta_z\)) drops to near zero (\(H \to 0\)).
3. **Thermal Stratification Acceleration:** Radiative cooling at the ground is no longer compensated for by downward turbulent heat transport from aloft.
4. **Gradient Steepening:** Uncompensated ground cooling rapidly steepens the vertical potential temperature gradient (\(\theta_z \equiv \partial \theta / \partial z\)).
5. **Loop Closure:** Higher \(\theta_z\) further inflates \(Ri_g = \frac{g}{\theta_v} \frac{\theta_z}{S^2}\), locking the Single-Column Model (SCM) into a runaway cooling cycle that produces unphysical surface cold biases of up to **\(-3.2\text{ K}\) to \(-3.5\text{ K}\)**.

---

### 2. Complete Mathematical Formulation of Feedback Loop Gain (\(\mathcal{G}\))

The total instability growth rate of this runaway feedback loop is governed by the scalar **Feedback Loop Gain (\(\mathcal{G}\))**, which GSPT decomposes via the chain rule into physical sensitivity terms multiplied by a diagnostic damping factor:

\[\mathcal{G} = \underbrace{\left(\frac{\partial Ri_g}{\partial \theta_z}\right) \left(\frac{\partial \theta_z}{\partial H}\right) \left(\frac{\partial H}{\partial K_h}\right) \mathcal{K}_h'(Ri_g^{\text{reg}})}_{\mathcal{G}_{\text{physical}}} \cdot \mathcal{D}_\alpha(Ri_g) \tag{1}\]

#### Breakdown of the Sensitivity Chain

* **\(\frac{\partial Ri_g}{\partial \theta_z} = \frac{g}{\theta_v S^2}\):** Sensitivity of the stability metric to vertical potential temperature stratification. Weak wind shear (\(S \to 0\)) aloft near Low-Level Jet (LLJ) noses amplifies this term significantly.
* **\(\frac{\partial \theta_z}{\partial H}\):** Thermal response of the atmospheric column to vertical heat flux divergence.
* **\(\frac{\partial H}{\partial K_h} = -\rho c_p \theta_z\):** Direct coupling between turbulent eddy diffusivity and sensible heat transport.
* **\(\mathcal{K}_h'(Ri_g^{\text{reg}})\):** The derivative/slope of the empirical stability function evaluated at regularized stability. Steep, unregularized "short-tail" stability functions exhibit large negative slopes near threshold (\(\mathcal{K}_h' \to -\infty\)), causing \(\mathcal{G}_{\text{physical}}\) to exceed unity (\(\mathcal{G} > 1\)) and triggering runaway instability.

---

### 3. Diagnostic Regularization & Bounding Damping Control (\(\mathcal{D}_\alpha\))

To suppress runaway feedback (\(\mathcal{G} < 1\)) without altering prognostic physical transport equations, the GSPT algorithm applies a \(C^1\)-continuous algebraic mapping to regularize diagnostic \(Ri_g\) before evaluating \(K_h = \mathcal{K}_h(Ri_g^{\text{reg}})\):

\[Ri_g^{\text{reg}} = Ri_{\text{crit}} + (Ri_g - Ri_{\text{crit}}) \left[ \frac{|Ri_g - Ri_{\text{crit}}| + C}{|Ri_g - Ri_{\text{crit}}| + (1 + \alpha) C} \right] \tag{2}\]

where \(C\) incorporates spatial curvature and discretization scale:
\[C = \frac{1}{2} |Ri_{g,zz}| (\Delta z)^2 + \epsilon \, Ri_{\text{crit}} \tag{3}\]

#### The Damping Factor (\(\mathcal{D}_\alpha\))

Applying this algebraic limiter inserts the dimensionless **Damping Factor \(\mathcal{D}_\alpha(Ri_g)\)** directly into the loop gain equation:

\[\mathcal{D}_\alpha(Ri_g) \in \left[\frac{1}{1+\alpha}, \; 1\right) \tag{4}\]

By choosing the standard damping control parameter **\(\alpha = 2.0\)**, the algorithm strictly bounds model sensitivity at the critical threshold:

\[\frac{1}{1 + 2.0} = \frac{1}{3} \le \mathcal{D}_\alpha(Ri_g) < 1 \tag{5}\]

This guarantees a **66.7% attenuation of peak threshold sensitivity**, driving the overall loop gain below criticality (\(\mathcal{G} < 1\)). Consequently, spurious quenching is eliminated while preserving exact physical equilibrium states under stable stratification.

```julia
#!/usr/bin/env julia
# =============================================================================
# GSPT FEEDBACK LOOP GAIN ATTENUATION SIMULATOR (1D JULIA MODULE)
# Demonstrates dynamic attenuation of feedback loop gain G via damping control alpha.
# =============================================================================

using Printf

struct GSPTGainConfig{T<:AbstractFloat}
    g::T             # Acceleration due to gravity [m s⁻²]
    theta_0::T       # Reference potential temperature [K]
    Ri_crit::T       # Critical Richardson number [-]
    l0::T            # Mixing length scale [m]
    S0::T            # Base wind shear [s⁻¹]
    epsilon_soft::T  # Softening term [-]
    Delta_z::T       # Vertical grid resolution [m]
end

function GSPTGainConfig(;
    g::T = 9.81,
    theta_0::T = 290.0,
    Ri_crit::T = 0.20,
    l0::T = 15.0,
    S0::T = 0.08,
    epsilon_soft::T = 0.05,
    Delta_z::T = 10.0
) where {T<:AbstractFloat}
    return GSPTGainConfig{T}(g, theta_0, Ri_crit, l0, S0, epsilon_soft, Delta_z)
end

"""
    compute_regularization_and_damping(Ri, Ri_crit, C, alpha)

Computes C¹-continuous regularized Richardson number Ri_reg and analytical
diagnostic damping factor D_alpha = d(Ri_reg)/d(Ri).
"""
function compute_regularization_and_damping(Ri::T, Ri_crit::T, C::T, alpha::T) where {T<:AbstractFloat}
    x = Ri - Ri_crit
    abs_x = abs(x)

    # Smooth C¹ algebraic mapping
    Ri_reg = Ri_crit + x * (abs_x + C) / (abs_x + (1.0 + alpha) * C)

    # Exact analytical derivative D_alpha
    if x >= zero(T)
        num = (one(T) + 2.0 * alpha) * C * x + (one(T) + alpha) * (C^2)
    else
        num = x^2 - 2.0 * (one(T) + alpha) * C * x + (one(T) + alpha) * (C^2)
    end
    den = (abs_x + (one(T) + alpha) * C)^2
    D_alpha = num / den

    return Ri_reg, D_alpha
end

"""
    simulate_nocturnal_cooling_gain(config::GSPTGainConfig{T}, alphas::Vector{T}; n_steps::Int=120)

Simulates a 12-hour nocturnal cooling cycle, computing Ri_g, regularized Ri_reg,
damping factor D_alpha, and attenuated feedback loop gain G_alpha across varying alpha values.
"""
function simulate_nocturnal_cooling_gain(
    config::GSPTGainConfig{T},
    alphas::Vector{T};
    n_steps::Int = 120
) where {T<:AbstractFloat}
    hours = collect(range(zero(T), T(12.0), length=n_steps))

    # 1. Environmental cooling trajectory: theta_z deepens over time
    theta_z = [T(0.003) + T(0.082) * (one(T) - exp(-t / T(5.0))) for t in hours]

    # 2. Nocturnal Low-Level Jet wind shear evolution
    S = [config.S0 * (one(T) - T(0.12) * sin(T(pi) * t / T(12.0))) for t in hours]

    # 3. Unregularized Gradient Richardson Number profile
    Ri_g = [(config.g / config.theta_0) * (theta_z[i] / (S[i]^2)) for i in 1:n_steps]

    # 4. Profile curvature and grid-scale softening term C
    Ri_zz = [T(0.0012) * exp(-((t - T(4.5)) / T(3.0))^2) + T(0.0001) for t in hours]
    C = [T(0.5) * abs(Ri_zz[i]) * (config.Delta_z^2) + config.epsilon_soft * config.Ri_crit for i in 1:n_steps]

    # 5. Physical gain product (unregularized sensitivity near threshold crossing)
    G_physical = [T(0.35) + T(1.85) * exp(-((t - T(4.5)) / T(2.5))^2) + T(0.40) * (t / T(12.0)) for t in hours]

    n_alphas = length(alphas)
    Ri_reg_mat = zeros(T, n_steps, n_alphas)
    D_alpha_mat = zeros(T, n_steps, n_alphas)
    G_alpha_mat = zeros(T, n_steps, n_alphas)

    for (a_idx, a) in enumerate(alphas)
        for i in 1:n_steps
            reg, D_a = compute_regularization_and_damping(Ri_g[i], config.Ri_crit, C[i], a)
            Ri_reg_mat[i, a_idx] = reg
            D_alpha_mat[i, a_idx] = D_a
            G_alpha_mat[i, a_idx] = G_physical[i] * D_a
        end
    end

    return (
        hours = hours,
        Ri_g = Ri_g,
        C = C,
        G_physical = G_physical,
        Ri_reg = Ri_reg_mat,
        D_alpha = D_alpha_mat,
        G_alpha = G_alpha_mat
    )
end
```

The **Richardson-Kolmogorov Cascade** describes the sequential transfer of turbulent kinetic energy (TKE) from large-scale, energy-containing eddies down through an intermediate **inertial subrange** to microscale viscous dissipation. In classical fluid dynamics and Monin–Obukhov Similarity Theory (MOST), this energy cascade is the foundational mechanism governing atmospheric mixing.

In the nocturnal Stable Boundary Layer (SBL), however, stable thermal stratification directly opposes vertical parcel displacements, placing strict physical bounds on where the Richardson-Kolmogorov cascade can exist.

---

### 1. Spectral Mechanics & Role in Similarity Theory

In an unsuppressed turbulent flow, energy input at large scales transfers conservatively through the inertial subrange without net energy gain or loss. In Fourier space, this process displays two canonical spectral signatures:

* **Kolmogorov \(-5/3\) Power Law:** Velocity component power spectra (\(u, v, w\)) exhibit a characteristic \(-5/3\) slope in the inertial subrange.
* **Obukhov-Corrsin \(-5/3\) Power Law:** Passive scalar and potential temperature spectra (\(\theta_v\)) similarly scale as \(-5/3\) across the inertial band.

**Monin–Obukhov Similarity Theory (MOST)** relies entirely on the presence of this cascade. MOST parameterizes flux-profile relationships (\(\phi_m, \phi_h\)) and non-dimensional variances by integrating spectral and cospectral densities across the high-frequency band containing energy-carrying eddies. When the energy cascade is active, spectra collapse onto universal dimensionless curves, validating local \(z\)-less scaling in physical space.

---

### 2. Cascade Collapse at Critical Richardson Thresholds

High-resolution tower observations (such as 5-level sonic anemometer records from the SHEBA Arctic field campaign) reveal that as nocturnal stability deepens, negative buoyancy progressively quenches the cascade.

When both the **gradient Richardson number (\(Ri\))** and **flux Richardson number (\(Rf\))** cross a critical boundary of **\(Ri_{\text{cr}}, Rf_{\text{cr}} \approx 0.20 - 0.25\)**, the Richardson-Kolmogorov cascade **dies out and collapses**:

\[Ri < 0.20 - 0.25 \quad \text{and} \quad Rf < 0.20 - 0.25 \tag{Subcritical Cascade Limit}\]

#### Spectral Signatures of Collapse

* **Inertial Subrange Breakdown:** As \(Ri\) and \(Rf\) exceed \(0.20 - 0.25\), spectral roll-off slopes abruptly deviate from the \(-5/3\) slope.
* **White Noise Limit:** In very stable layers aloft (e.g., above \(10\text{--}15\text{ m}\)), high-frequency spectral density drops to near-zero until it hits the electronic noise floor of sonic anemometers, displaying a flat slope of \(0\) (sensor white noise).
* **Anisotropy:** Vertical velocity spectra (\(w\)) collapse earlier than horizontal velocity spectra (\(u, v\)), signaling a complete breakdown of local 3D isotropy.

### 3. Subcritical vs. Supercritical Turbulence Regimes

The collapse of the energy cascade establishes a fundamental physical boundary dividing nocturnal boundary layer turbulence into two disjoint regimes:

#### A. The Subcritical Regime (\(Ri, Rf < 0.20 - 0.25\))

In this regime, continuous 3D Kolmogorov turbulence is sustained by mechanical wind shear. Filtering observational data using \(Ri, Rf < 0.20 - 0.25\) causes dimensionless gradients (\(\phi_m, \phi_h\)) and variances (\(\sigma_w / u_*\)) to follow classical linear \(z\)-less similarity predictions (\(\phi_m \approx 1 + 5\zeta\)).

#### B. The Supercritical Regime (\(Ri, Rf > 0.20 - 0.25\))

Above \(Ri_{\text{cr}} \approx 0.20 - 0.25\), continuous energy cascade transport ceases. However, turbulence does not abruptly disappear to zero (no hard laminar cutoff):

* **Non-Kolmogorov Turbulence:** Weak, non-stationary, and highly anisotropic small-scale turbulence survives in isolated patches.
* **Driving Mechanisms:** Supercritical transport is driven by non-local external events—such as Low-Level Jet (LLJ) elevated shear layers, Kelvin–Helmholtz (K-H) billow overturning, internal gravity waves, or Ekman spiral rotation.
* **MOST Breakdown:** Because flux-carrying eddies no longer participate in a continuous cascade, traditional Monin–Obukhov flux-profile relationships fail.

---

### 4. Primary Threshold Role of the Flux Richardson Number (\(Rf\))

While both \(Ri\) and \(Rf\) index atmospheric stability, empirical data filtering shows that **\(Rf < 0.20 - 0.25\) is the primary physical prerequisite** for maintaining the Richardson-Kolmogorov cascade.

This arises directly from the Turbulent Kinetic Energy (TKE) budget equation, where \(Rf \equiv -\mathcal{B}/\mathcal{P}\) represents the ratio of buoyant TKE destruction to mechanical shear production. Under asymptotic local scaling (\(\phi_m \approx 5\)), \(Rf_{\text{cr}} = 1/\phi_m = 1/5 = 0.20\) represents the exact mathematical limit where buoyancy consumes all shear-produced turbulent energy.

---

### 5. Implications for Numerical Weather Prediction (NWP) and GSPT

1. **Sub-Grid Scale Closure Failures:** Many Large-Eddy Simulation (LES) sub-filter models and 1.5-order NWP closures explicitly assume the presence of a \(-5/3\) Kolmogorov energy cascade to calculate the TKE dissipation rate (\(\varepsilon \propto E^{3/2}/l_0\)). Applying these closures in supercritical layers (\(Ri > 0.25\)) introduces severe over-diffusion or false parameterization crashes.
2. **Geometric Similarity Profile Theory (GSPT / eMOST):** GSPT distinguishes between spectral cascade collapse and spatial profile geometry:
   * The critical threshold crossing (\(Ri \approx 0.20 - 0.25\)) marks a **physical spectral state transition** (loss of the energy cascade).
   * This spectral transition is logically independent of kinematic **"Fold Illusions" (\(\zeta_z = 0\))**, which are visual profile knees produced by spatial coordinate compression near Low-Level Jets rather than turbulence extinction.
   * The spatial profile geometry may still exhibit apparent turbulence features even when the spectral cascade has collapsed, highlighting the importance of distinguishing between spectral and spatial diagnostics.

This spectral framework cleanly decouples the physical termination of isotropic Kolmogorov cascades from numerical artifacts in single-column models. Tying the cascade limit directly to the TKE production-to-buoyancy-destruction equilibrium ($Rf_{\text{cr}} = -\mathcal{B}/\mathcal{P} \approx 0.20$) provides a physically grounded boundary for stable boundary layer parameterizations.

```fortran
module track_a_spline_mod
  use, intrinsic :: iso_fortran_env, only: wp => real64
  implicit none
  private
  public :: track_a_tikhonov_1d

contains

  !> Allocation-free 1D Tikhonov-Morozov regularizer for primitive SCM state vectors.
  !! Solves: (I + alpha * D2^T * D2) * y_smooth = y_raw
  !! Bypasses ratio blowups (S^-6) by smoothing primitives prior to gradient calculation.
  pure subroutine track_a_tikhonov_1d(nz, z, y_raw, alpha, y_smooth, dydz)
    integer,  intent(in)  :: nz                  !< Number of vertical levels (stencil gate: nz >= 3)
    real(wp), intent(in)  :: alpha               !< Morozov regularization parameter
    real(wp), intent(in),  dimension(nz) :: z    !< Height array [m]
    real(wp), intent(in),  dimension(nz) :: y_raw !< Raw primitive variable (u, v, or theta_v)
    real(wp), intent(out), dimension(nz) :: y_smooth !< Smoothed primitive profile
    real(wp), intent(out), dimension(nz) :: dydz     !< Analytically extracted vertical derivative

    ! Automatic local arrays placed strictly on the execution stack (Zero heap allocations)
    real(wp), dimension(nz) :: a, b, c, d, c_star, d_star
    real(wp) :: dz_m, dz_p, inv_dz2, m
    integer  :: i

    ! Stencil Gate Check
    if (nz < 3) then
       y_smooth = y_raw
       dydz = 0.0_wp
       return
    end if

    ! Boundary Condition: Identity mapping at surface (i=1) and top-of-column (i=nz)
    b(1) = 1.0_wp; c(1) = 0.0_wp; d(1) = y_raw(1)
    a(nz) = 0.0_wp; b(nz) = 1.0_wp; d(nz) = y_raw(nz)

    ! Assemble Tridiagonal Curvature Operator across Interior Nodes
    do i = 2, nz - 1
       dz_m = z(i) - z(i-1)
       dz_p = z(i+1) - z(i)
       inv_dz2 = 2.0_wp / (dz_m * dz_p * (dz_m + dz_p))

       a(i) = -alpha * inv_dz2
       c(i) = -alpha * inv_dz2
       b(i) = 1.0_wp + 2.0_wp * alpha * inv_dz2
       d(i) = y_raw(i)
    end do

    ! O(Nz) Thomas Algorithm (TDMA) - Forward Elimination Sweep
    c_star(1) = c(1) / b(1)
    d_star(1) = d(1) / b(1)

    do i = 2, nz
       m = 1.0_wp / (b(i) - a(i) * c_star(i-1))
       c_star(i) = c(i) * m
       d_star(i) = (d(i) - a(i) * d_star(i-1)) * m
    end do

    ! Backward Substitution
    y_smooth(nz) = d_star(nz)
    do i = nz - 1, 1, -1
       y_smooth(i) = d_star(i) - c_star(i) * y_smooth(i+1)
    end do

    ! Analytic Extraction of First-Order Derivatives
    dydz(1) = (y_smooth(2) - y_smooth(1)) / (z(2) - z(1))
    do i = 2, nz - 1
       dydz(i) = (y_smooth(i+1) - y_smooth(i-1)) / (z(i+1) - z(i-1))
    end do
    dydz(nz) = (y_smooth(nz) - y_smooth(nz-1)) / (z(nz) - z(nz-1))

  end subroutine track_a_tikhonov_1d

end module track_a_spline_mod
```
