The classical interpretation of Stable Boundary Layer (SBL) vertical soundings is that localized inflection features ("knees"), where the gradient Richardson number (\(Ri_g\)) crosses the critical threshold \(Ri_c \approx 0.25\), represent autonomous physical bifurcations indicating the local extinction of turbulent mixing.

Generalized Similarity Profile Theory (GSPT) demonstrates that an observed threshold crossing in physical vertical space (\(z\)) is **insufficient evidence** to infer a local dynamical saddle-node bifurcation. Instead, profile knees frequently arise as **coordinate projection artifacts** of the similarity mapping \(\zeta(z) = \frac{z}{L(z)}\), a phenomenon known as a **"Fold Illusion"**. To mathematically separate true physical transitions from geometric coordinate artifacts, GSPT provides a rigorous framework of curvature decomposition and error partitioning.

---

### 1. Differential Geometry of Profile Curvature

Evaluating physical-space profile morphology requires analyzing the vertical second derivative of the gradient Richardson number, \(Ri_{zz} \equiv \frac{\partial^2 Ri}{\partial z^2}\). Applying the multi-variable chain rule to an arbitrary similarity relation \(Ri(z) = R(\zeta(z))\) yields the total vertical spatial curvature decomposition:

\[Ri_{zz} = \underbrace{R_{\zeta\zeta}\zeta_z^2}_{C_{\text{constitutive}}} + \underbrace{R_\zeta\zeta_{zz}}_{C_{\text{mapping}}}\]

*   **Constitutive Curvature (\(C_{\text{constitutive}}\)):** Represents the curvature of the empirical similarity relation transformed into physical \(z\)-space. Because it contains the coordinate gradient squared (\(\zeta_z^2\)), it remains dependent on local coordinate stretching. Its magnitude scales as \(O(\zeta_z^2)\).
*   **Mapping Curvature (\(C_{\text{mapping}}\)):** Represents the pure geometric curvature generated by the non-linear coordinate mapping \(z \mapsto \zeta(z)\). It scales as \(O(\zeta_z)\) (for non-local flux divergence where \(L' \neq 0\)).

#### Scaling Behavior Near Coordinate Turning Limits (\(\zeta_z \to 0\))
As the coordinate Jacobian approaches zero (\(\zeta_z \to 0\)), taking the ratio of relative magnitudes reveals that the mapping term asymptotically dominates:
\[\frac{|C_{\text{mapping}}|}{|C_{\text{constitutive}}|} \to \infty\]

However, the total spatial curvature \(Ri_{zz}\) does not diverge. At a local coordinate turning point where \(\zeta_z(z_*) = 0\):
\[Ri_z(z_*) = R_\zeta(\zeta_*) \zeta_z(z_*) = 0\]
\[Ri_{zz}(z_*) = R_\zeta(\zeta_*) \zeta_{zz}(z_*)\]

Because \(R_\zeta = (1+\beta_m\zeta)^{-2} > 0\) under standard linear closures, a nondegenerate coordinate fold (\(\zeta_{zz}(z_*) \neq 0\)) yields a finite vertical curvature:
\[Ri_{zz}(z_*) = \frac{\zeta_{zz}(z_*)}{(1+\beta_m\zeta_*)^2} \neq 0\]

Thus, the physical-space profile exhibits a finite, smooth, quadratic turning point (where the slope vanishes) rather than an explosive spatial singularity.

---

### 2. Tri-Singularity Classification Framework

To eliminate ambiguity between empirical closures, spatial projections, and physical fluid instabilities, GSPT formalizes three distinct geometric domains:

| Geometric Domain | Mathematical Operator / Relation | Critical Condition | Physical & Computational Interpretation |
| :--- | :--- | :--- | :--- |
| **Constitutive Geometry** | \(Ri = R(\zeta)\) | N/A | Governing similarity relation resulting from closed momentum/heat stability functions (e.g., \(\phi_m, \phi_h\)). |
| **Observation-Coordinate Geometry** | \(\zeta = \zeta(z)\) | \(\zeta_z(z_*) = 0, \quad \zeta_{zz}(z_*) \neq 0\) | Kinematic transformation artifact creating quadratic profile turning points (\(Ri_z = 0\)) in 1D vertical space. |
| **Dynamical State-Space Geometry** | \(\dot{X} = F(X, \mu)\) | \(F(X_*, \mu_*) = 0, \quad \det D_X F = 0\) | True dynamical saddle-node bifurcation corresponding to the local collapse/extinction of the turbulent kinetic energy manifold. |

**A coordinate fold is not a dynamical fold (\(\zeta_z = 0 \centernot\implies \det D_X F = 0\))**; they represent singularities in entirely different mathematical spaces. This is a core conclusion of SBL geometric analysis: **the threshold crossing \(Ri_g = Ri_c\) is neither a coordinate-fold criterion nor a saddle-node criterion**.

---

### 3. Conditions for Coordinate Turning Points and Folds

Coordinate regimes are governed by the vertical structure of the Obukhov length profile, \(L(z)\). Defining the stationary function \(F(z) = L(z) - z L'(z)\) such that \(\zeta_z = \frac{F(z)}{L(z)^2}\), the generic coordinate turning point criteria are:

1.  **Stationary Condition:** \(\zeta_z(z_*) = 0 \iff L(z_*) = z_* L'(z_*)\)
2.  **Nondegeneracy Condition:** \(\zeta_{zz}(z_*) = -\frac{z_* L''(z_*)}{L(z_*)^2} \neq 0 \iff L''(z_*) \neq 0\)

#### The Linear Obukhov Profile Test
Under a strictly linear Obukhov length profile \(L(z) = L_0 + L'z\) (where \(L'' = 0\)):
\[\zeta_z = \frac{L_0}{(L_0 + L'z)^2} > 0\]

Because \(\zeta_z\) is strictly positive for all finite \(z\), **no finite coordinate fold can exist under a linear Obukhov profile**. As \(z \to \infty\), the coordinate asymptotically compresses toward \(1/L'\). Therefore, a visually sharp "knee" in physical space cannot be classified as a coordinate fold unless independent evidence establishes an actual zero of \(\zeta_z\) at a finite height, serving as an important safeguard against over-interpreting the GSPT coordinate mechanism.

---

### 4. Operational SCM Error Partitioning

When Single-Column Models (SCMs) misrepresent stable boundary layer profiles, developers frequently retune local Monin-Obukhov constants (\(\beta_m, \beta_h\)). GSPT prevents this compensating error by operationally partitioning the model-observation residual (\(\Delta_{\text{SCM}}\)):

\[\Delta_{\text{SCM}} \equiv (C_{\text{const}}^{\text{SCM}} + C_{\text{coord}}^{\text{SCM}}) - Ri_{zz}^{\text{obs}} = \Delta_{\text{closure}} + \Delta_{\text{geom}} + \tau_{\Delta z}\]

*   **Constitutive Failure (\(|\Delta_{\text{closure}}| \gg 0\), \(\Delta_{\text{geom}} \approx 0\)):** Local turbulence closure functions are inaccurate. Developers must adjust the stability parameters \(\phi_m(\zeta), \phi_h(\zeta)\) (e.g., transitioning from Businger-Dyer to the SHEBA-calibrated Grachev 2007 formulation).
*   **Coordinate Distortion (\(|\Delta_{\text{geom}}| \gg 0\), \(\Delta_{\text{closure}} \approx 0\)):** Excessive vertical mixing is over-smoothing the heat and momentum flux divergence profiles (\(L', L''\)). Developers must adjust mixing lengths (\(l_m\)), local TKE closures, or vertical transport—**leaving the stability functions \(\phi_m/\phi_h\) untouched**.
*   **Discretization Artifact (\(\tau_{\Delta z} \gg 0\)):** Coarse vertical model grid spacing fails to capture fine-scale vertical gradient non-linearities. This requires a Taylor truncation correction:
    \[\mathcal{E}_{\Delta z} \approx \frac{(\Delta z)^2}{12}\frac{\Delta^4 Ri}{\Delta z^4}\]

---

### 5. Low-Level Jet Nose and the Fold Ratio

Near the axis of a Low-Level Jet (LLJ), wind shear vanishes (\(U_z \to 0\)), driving raw \(Ri_g \to \infty\) and collapsing the local Obukhov length (\(L \to 0\)). To isolate this mathematical singularity, the pipeline evaluates the **Fold Ratio**:

\[\text{Fold Ratio} = \frac{|C_{\text{mapping}}|}{|C_{\text{constitutive}}| + |C_{\text{mapping}}|} > 0.99\]

When the Fold Ratio exceeds 0.99, the diagnostic engine bypasses standard Tikhonov smoothing on \(Ri_g\) and evaluates stability strictly in flux-divergence coordinates (\(L, L', L''\)), preventing the coordinate singularity from corrupting curvature calculations in adjacent boundary layer sub-layers.

---

### 6. Preprocessing Operator Non-Commutation

Computing Richardson profiles involves non-linear quotient operations (\(\mathcal{Q}\)) and discrete derivatives (\(D_{\Delta z}\)) that do not commute with spatial Tikhonov-Morozov smoothing spline filters (\(M_\delta\)):

1.  **Differential-Smoothing Non-Commutation:** \(M_\delta D_{\Delta z} \neq D_{\Delta z} M_\delta\)
2.  **Quotient-Smoothing Non-Commutation:** \(\mathcal{Q}[D_{\Delta z} M_\delta u, D_{\Delta z} M_\delta v, D_{\Delta z} M_\delta \theta_v] \neq M_\delta \mathcal{Q}[D_{\Delta z} u, D_{\Delta z} v, D_{\Delta z} \theta_v]\)

Because of this non-commutation, data pipelines **must** apply regularization filters (\(M_\delta\)) directly to the primitive fields (\(u, v, \theta_v\)) prior to differentiation:

\[Ri_g^{(\delta)} = \frac{\frac{g}{M_\delta \theta_v} D_{\Delta z}(M_\delta \theta_v)}{\left[D_{\Delta z}(M_\delta u)\right]^2 + \left[D_{\Delta z}(M_\delta v)\right]^2}\]

Applying the spline smoother directly to raw, calculated \(Ri_g\) values instead of primitive variables silently manufactures unphysical coordinate geometry, particularly around low-shear regions.

# ==============================================================================
# STAGE 6: CLOSURE COMPARISON & SCM ERROR PARTITIONING MODULE
# ==============================================================================

struct Stage6ComparisonResult
    z::Vector{Float64}
    Ri_g::Vector{Float64}
    zeta_BD::Vector{Float64}
    zeta_G07::Vector{Float64}
    delta_zeta::Vector{Float64}          # ζ_G07 - ζ_BD
    Delta_closure::Vector{Float64}       # Structural closure residual (C_const_G07 - C_const_BD)
    Delta_geom::Vector{Float64}          # Coordinate distortion residual (C_map_G07 - C_map_BD)
    tau_discretization::Vector{Float64}  # Spatial Taylor truncation correction (τ_Δz)
    fold_ratio_BD::Vector{Float64}       # |C_mapping| / (|C_const| + |C_mapping|)
    fold_ratio_G07::Vector{Float64}
end

"""
    run_stage6_closure_comparison(z, theta_z, U_z, L_profile, L_p_profile, L_pp_profile; theta_ref=273.15, g=9.81)

Executes Stage 6 comparison between Businger-Dyer and Grachev (2007) closures. Enforces
primitive-first regularization Q[M_δ u, M_δ v, M_δ θ_v] to avoid non-commutation operator artifacts.
"""
function run_stage6_closure_comparison(
    z::Vector{Float64},
    theta_z::Vector{Float64},
    U_z::Vector{Float64},
    L_profile::Vector{Float64},
    L_p_profile::Vector{Float64},
    L_pp_profile::Vector{Float64};
    theta_ref=273.15,
    g=9.81
)
    N = length(z)

    # Primitive-First Derivative Quotient: Q[M_δ θ_v, M_δ u, M_δ v]
    U_z_guarded = max.(abs.(U_z), 1e-4)
    Ri_g = (g ./ theta_ref) .* theta_z ./ (U_z_guarded .^ 2)
    Ri_g_guarded = min.(Ri_g, 0.19)

    zeta_BD = zeros(N)
    zeta_G07 = zeros(N)
    C_const_BD = zeros(N)
    C_mapping_BD = zeros(N)
    C_const_G07 = zeros(N)
    C_mapping_G07 = zeros(N)

    for i in 1:N
        # --- Businger-Dyer Closure ---
        z_bd = Ri_g_guarded[i] / (1.0 - 5.0 * Ri_g_guarded[i])
        zeta_BD[i] = z_bd
        denom_bd = 1.0 + 5.0 * z_bd
        R_zeta_bd = 1.0 / (denom_bd^2)
        R_zeta_zeta_bd = -10.0 / (denom_bd^3)

        # --- Grachev et al. (2007) Closure ---
        z_g07, dzeta_dRi = invert_grachev_Ri(Ri_g_guarded[i])
        zeta_G07[i] = z_g07
        phi_m, phi_h = eval_grachev_phi(z_g07)
        R_zeta_g07 = 1.0 / max(dzeta_dRi, 1e-6)
        R_zeta_zeta_g07 = -2.0 * 5.0 / ((1.0 + 5.0 * z_g07)^3)

        # --- Coordinate Kinematics & Mapping Terms ---
        L = L_profile[i]
        L_p = L_p_profile[i]
        L_pp = L_pp_profile[i]

        # BD Kinematics
        zeta_z_bd = (1.0 - z_bd * L_p) / L
        zeta_zz_bd = -2.0 * (L_p / L) * zeta_z_bd - (z_bd * L_pp / L)
        C_const_BD[i] = R_zeta_zeta_bd * (zeta_z_bd^2)
        C_mapping_BD[i] = R_zeta_bd * zeta_zz_bd

        # G07 Kinematics
        zeta_z_g07 = (1.0 - z_g07 * L_p) / L
        zeta_zz_g07 = -2.0 * (L_p / L) * zeta_z_g07 - (z_g07 * L_pp / L)
        C_const_G07[i] = R_zeta_zeta_g07 * (zeta_z_g07^2)
        C_mapping_G07[i] = R_zeta_g07 * zeta_zz_g07
    end

    delta_zeta = zeta_G07 .- zeta_BD
    Delta_closure = C_const_G07 .- C_const_BD
    Delta_geom = C_mapping_G07 .- C_mapping_BD

    # Discrete Taylor Truncation Correction (τ_Δz ≈ (Δz)^2 / 12 * Δ^4 Ri / Δz^4)
    dz = N > 1 ? (z[end] - z[1]) / (N - 1) : 1.0
    Ri_4th_diff = zeros(N)
    if N >= 5
        for i in 3:(N-2)
            Ri_4th_diff[i] = (Ri_g[i+2] - 4*Ri_g[i+1] + 6*Ri_g[i] - 4*Ri_g[i-1] + Ri_g[i-2]) / (dz^4)
        end
    end
    tau_discretization = ((dz^2) / 12.0) .* Ri_4th_diff

    # Fold Ratio Evaluations
    fold_ratio_BD = abs.(C_mapping_BD) ./ (abs.(C_const_BD) .+ abs.(C_mapping_BD) .+ 1e-12)
    fold_ratio_G07 = abs.(C_mapping_G07) ./ (abs.(C_const_G07) .+ abs.(C_mapping_G07) .+ 1e-12)

    return Stage6ComparisonResult(
        z, Ri_g, zeta_BD, zeta_G07, delta_zeta,
        Delta_closure, Delta_geom, tau_discretization,
        fold_ratio_BD, fold_ratio_G07
    )
end

| **Inflection Check** | $C_{\text{const}} \approx -C_{\text{mapping}}$ | "Fold Illusion" knee event. Inflection point is a spatial coordinate projection artifact. | Do not alter physical stability functions $\phi_m/\phi_h$; profile knee is kinematic. |
