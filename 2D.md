# 2D Fast-Slow SBL Model

**Physics & Parameterization (Atmospheric Science)**

The model captures non-linear coupling between stable boundary-layer wind shear and turbulent kinetic energy (TKE).

* **Fast Variable $e$ (TKE, $\text{m}^2/\text{s}^2$):** Relaxes on timescale $\epsilon \ll 1$. Its balance consists of shear production $\mathcal{P}$, regularized buoyancy flux $\mathcal{B}(e)$, and viscous dissipation $\varepsilon_{\text{diss}}$:

$$\epsilon \frac{de}{dt} = \mathcal{P} - \mathcal{B}(e) - \varepsilon_{\text{diss}} = l_0 e S^2 - B_{0,\max} \left(\frac{e^2}{e^2 + \delta_{\text{reg}}^2}\right) - \frac{e^3}{l_0 \left(1 + \beta N^2 / S^2\right)}$$

* **Hill-Type Saturating Regularization ($\delta_{\text{reg}}$):** Rather than a polynomial expansion, $\mathcal{B}(e)$ is a Hill-type rational function (Hill coefficient $n=2$). Near $e \to 0$, $\mathcal{B}(e) \approx B_{0,\max}\frac{e^2}{\delta_{\text{reg}}^2} + \mathcal{O}(e^4)$, yielding an exact zero-TKE equilibrium with fast repelling linearized growth $\left.\frac{\partial \dot{e}}{\partial e}\right\vert{}_{e=0} = \frac{l_0 S^2}{\epsilon} > 0$ for $S > 0$ (modeling shear-driven turbulent reignition). For $e \gg \delta_{\text{reg}}$, it smoothly saturates to the physical cap $B_{0,\max}$.
* **Slow Variable $S$ (Wind Shear, $\text{s}^{-1}$):** Driven by synoptic geostrophic forcing $G_0$, offset by turbulent shear stress extraction $\gamma_s e S$ and background relaxation $r_s S$:

$$\frac{dS}{dt} = G_0 - \gamma_s e S - r_s S$$

**Fast-Slow Dynamical System (Mathematics)**

The system is expressed in singular perturbation form $(\dot{e}, \dot{S}) = (\frac{1}{\epsilon} F(e,S), g(e,S))$.

* **Critical Manifold ($\mathcal{C}_0$):** The algebraic zero locus of the fast vector field:

$$\mathcal{C}_0 = \left\{(e,S) \in \mathbb{R}_{\ge 0}^2 \;\middle\vert{}\; F(e, S; \delta_{\text{reg}}) = 0\right\}$$

* **Normal Hyperbolicity ($\mathcal{C}_0^+$):** The manifold sheet is normally attracting where the scalar fast eigenvalue is strictly negative:

$$\lambda_{\text{fast}} = \frac{1}{\epsilon} \frac{\partial F}{\partial e} < 0$$

* **Saddle-Node Fold Boundary ($\partial \mathcal{C}_0$):** Point of normal hyperbolicity loss ($\lambda_{\text{fast}} = 0$) where stable turbulence collapses into the laminar state, defined by the 2D root system:

$$F(e,S;\delta_{\text{reg}}) = 0 \quad \text{and} \quad \frac{\partial F}{\partial e}(e,S;\delta_{\text{reg}}) = 0$$

**Implementation Architecture**

| Theoretical Concept | Mathematical Formulation | Code Realization (`src/gspt_saddle_node_trajectory.jl`) |
| --- | --- | --- |
| **Critical Fold Boundary** | $F(e,S) = 0, \, \frac{\partial F}{\partial e} = 0$ | 2D Newton-Raphson scheme in `solve_regularized_fold()` |
| **Fast Subsystem Stability** | $\lambda_{\text{fast}} = \frac{1}{\epsilon} \frac{\partial F}{\partial e}$ | Scalar partial derivative evaluation in `fast_manifold_jac()` |
| **Scalar Manifold Distance** | $d_C^* = \frac{\Vert{}F(e,S)\Vert{}}{\max\left(1, \left\Vert{}\frac{\partial F}{\partial e}\right\Vert{}e + \left\Vert{}\frac{\partial F}{\partial S}\right\Vert{}S\right)}$ | Step-by-step absolute value scalar metric tracking trajectory distance to $\mathcal{C}_0$ |
